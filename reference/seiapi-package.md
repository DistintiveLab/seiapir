# seiapi: Cliente R para o SEI via API REST (mod-wssei) e Web

Pesquisa, obtém e inclui documentos/processos no Sistema Eletrônico de
Informações (SEI) por meio do módulo REST mod-wssei (backend 'wssei')
ou, como fallback, por emulação da sessão web via SIP (backend 'web',
rvest/httr2).
